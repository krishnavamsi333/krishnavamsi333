## 🚀 Featured Projects

### 🔋 **48V Lithium BMS with Active Cell Balancing**
**Tech Stack:** C++, STM32H7, CAN FD, LiPo 48V nominal  
**Status:** ✅ Production-Ready Prototype

- **Real-time monitoring** of 16 series cells with ±10mV accuracy using differential ADC sampling
- **Active cell balancing** using switched-resistor network; reduces pack imbalance from 2.5V → <0.1V in 2 hours
- **Safety-critical firmware**: Over-current cutoff (<2ms response), over-temperature alerts, deep-discharge protection
- **CAN bus interface** for telemetry logging and integration with vehicle controller
- **Testing**: 500+ charge/discharge cycles; validated across -10°C to 60°C temperature range
- 📊 **Result:** 15% improvement in usable energy density vs. passive balancing

**Live Demo:** [View Repository](https://github.com/krishnavamsi333) | [BMS Dashboard](https://github.com/krishnavamsi333)

### ☀️ **Solar MPPT Charge Controller (Hardware + Firmware)**
**Tech Stack:** MATLAB/Simulink, STM32F4, boost converter topology, LTspice  
**Status:** ✅ Prototype → PCB Manufacturing

- **Algorithm:** Perturb & Observe (P&O) MPPT with **95.3% peak efficiency** across irradiance profiles
- **Hardware**: 600W input power rating, 12V/24V/48V battery charging modes, soft-start PWM
- **Simulations**: Dynamic model tested across 200-1000 W/m² irradiance with <2-second MPPT convergence
- **Real-world testing**: 40-hour solar logging under variable cloud cover; 94.7% avg efficiency in field conditions
- **Firmware**: C++ implementation with state machine architecture; 100Hz PWM switching frequency
- 📊 **Result:** Expected 18-22% more daily energy harvest vs. constant-voltage charging

**Publications & Demos:** [MATLAB Model](https://github.com/krishnavamsi333) | [Hardware Schematic](https://github.com/krishnavamsi333)

### 🤖 **LiDAR-Based Autonomous Agricultural Robot (Agri-Bot)**
**Tech Stack:** ROS 2 Humble, Python, LiDAR (RPLiDAR A1), OpenCV, SLAM, Nav2 stack  
**Status:** ✅ Field-Tested on 5-hectare Farm

- **Autonomous Navigation**: Real-time 2D SLAM using Cartographer; `<5cm` localization error in GPS-denied environments
- **Sensor Fusion**: RPLiDAR (360° scans) + wheel odometry + IMU for robust path estimation
- **Obstacle Avoidance**: Dynamic Window Approach (DWA) with ~95% detection rate for field obstacles (rocks, furrows)
- **Mission Planning**: Autonomous grid-based surveying; covers 5 hectares in 3 hours with human-in-loop safety override
- **Deployment**: Containerized ROS 2 stack on Raspberry Pi 4; live telemetry via MQTT
- 📊 **Result:** 80% reduction in manual field surveying time; validated across 50+ autonomous missions

### ⚡ **DC-DC Converter Design & PCB Layout**
**Tech Stack:** LTspice, Altium Designer, STM32F1 (PWM control)  
**Type:** Buck and Boost topologies

- **Boost Converter**: 12V → 48V, 100W continuous, designed for solar + battery hybrid systems
- **Buck Converter**: 48V → 12V, multi-output (auxiliary supplies), integrated over-current sensing
- **Efficiency**: ≥92% measured at rated load; thermal simulations validated PCB layout
- **Layout**: 4-layer board with dedicated power/ground planes, star-point distribution, <50mΩ trace resistance
- **Testing**: ±5% line/load regulation, <50mV ripple under step-load transients
- 📊 **Result:** Hand-soldered prototypes with zero magic smoke 🎆

**Schematics & Layouts:** [KiCad Files](https://github.com/krishnavamsi333) | [LTspice Simulations](https://github.com/krishnavamsi333)
